# Evidencias — Pruebas de usuarios reales

## Propósito

Esta carpeta está reservada para documentar o indexar evidencias asociadas a las pruebas reales.

## Regla de privacidad

No se deben incorporar al repositorio datos personales, nombres, contactos, capturas o grabaciones que permitan identificar innecesariamente a participantes.

Cuando una evidencia requiera conservar material sensible, debe mantenerse fuera de este repositorio y registrar únicamente una referencia operativa, hash o identificador interno cuando corresponda.

## Evidencias admisibles para el registro

- descripción factual del comportamiento;
- registro verificable de envío/convocatoria;
- captura técnica no identificativa;
- logs relevantes;
- referencias a issues;
- commit/deployment probado;
- metadatos de entorno;
- transcripción anonimizada cuando sea estrictamente necesaria.

## Trazabilidad

La relación mínima recomendada es:

TEST-ID → fecha/sesión → evidencia → observación → incidencia/hallazgo.

Para hitos de convocatoria o envío puede utilizarse:

TEST-ID → fecha/hora de envío → evidencia del envío.

Los resultados deben distinguir claramente entre evidencia disponible y valoración posterior.
