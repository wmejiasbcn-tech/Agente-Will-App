# 11 — Metodología y desarrollo

## Método
El desarrollo documentado de Budd/Chemified utilizó Intervention Mapping Protocol y una evaluación estructurada de necesidades.

## Componentes documentados
- revisión de literatura científica;
- entrevistas semiestructuradas;
- identificación de necesidades y determinantes;
- teorías de cambio conductual;
- definición de objetivos de intervención;
- co-diseño/participación de usuarios;
- prototipado y pilotaje;
- evaluación posterior.

## Teorías citadas en el trabajo de desarrollo
- Social Cognitive Theory.
- Theory of Planned Behavior.
- Precaution Adoption Process Model.
