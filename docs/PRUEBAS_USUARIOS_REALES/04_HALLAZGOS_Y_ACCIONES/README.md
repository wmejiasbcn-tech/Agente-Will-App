# Hallazgos y acciones — Pruebas de usuarios reales

## Propósito

Consolidar los resultados de las pruebas reales sin convertir automáticamente una observación individual en requisito de producto.

## Tipos de registro

### OBSERVACIÓN
Hecho relatado o comportamiento observado en una prueba concreta.

### INCIDENCIA
Comportamiento no esperado o defecto que requiere investigación o corrección.

### PATRÓN
Comportamiento u observación que se repite en varias pruebas.

### HALLAZGO
Conclusión operativa derivada del análisis de observaciones y/o patrones.

### ACCIÓN
Cambio, investigación, issue, experimento o decisión derivada de un hallazgo.

## Regla de cierre

Una acción debe mantener trazabilidad hasta las pruebas que la motivaron.

Formato recomendado:

TEST-IDs → observaciones/evidencias → hallazgo → acción → resultado de verificación.
