# 03 — Arquitectura y funcionalidades

Budd es una web-app/mHealth orientada a acompañar situaciones relacionadas con chemsex. La información disponible describe una estructura de uso que cubre antes, durante y después de una sesión.

## Módulos/recursos observados o documentados
- Combo tool / herramientas de combinación.
- Chems / información sobre sustancias.
- Support & Care.
- Emergency.
- Articles.
- Chemsex Stories.
- Herramientas de planificación y checklists.
- Seguimiento/registro de determinadas variables de la sesión.
- Recursos de apoyo.

## Criterio de evidencia
Distinguir funcionalidad actualmente visible de funcionalidad descrita en publicaciones o versiones anteriores. No asumir que una descripción histórica implica disponibilidad actual.
