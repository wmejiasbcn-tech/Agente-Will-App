# ESTÁNDAR DE BÚSQUEDA DE RECURSOS WILL v1.0

## Orden obligatorio
1. Centros comunitarios y ONG especializadas.
2. Centros sociosanitarios especializados.
3. Centros sanitarios especializados.
4. Centros hospitalarios.

Dentro de cada nivel: pertinencia temática/especificidad → proximidad.

## Pertinencia
Solo se presentan recursos con indicios en nombre, descripción, especialidad o clasificación de relación con salud sexual, VIH/ITS, PrEP/PEP, sexualidad, LGBT/LGBTI, sustancias, adicciones, Chemsex, SLAM, reducción de riesgos/daños o apoyo comunitario relacionado.

## Exclusiones
Farmacias, odontología, veterinaria, podología, maternidad, ortopedia, optometría, oftalmología, fisioterapia y otros servicios sin relación con los temas de Will.

## Cobertura
La búsqueda acepta ciudad, región, país o lugar y es independiente del país. Las fuentes abiertas no permiten afirmar que se hayan encontrado literalmente todos los recursos existentes; Will no inventará resultados ni confundirá ausencia de datos con inexistencia.
