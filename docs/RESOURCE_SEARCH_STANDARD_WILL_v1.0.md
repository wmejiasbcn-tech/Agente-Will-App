# ESTÁNDAR DE BÚSQUEDA DE RECURSOS WILL v1.0

## Orden obligatorio
1. Centros comunitarios y ONG especializadas.
2. Centros sociosanitarios especializados.
3. Centros sanitarios especializados.
4. Centros hospitalarios.

Dentro de cada nivel: pertinencia temática y especificidad → proximidad.

## Regla de pertinencia
La proximidad por sí sola nunca convierte un establecimiento en recurso de Will. Debe existir un indicio en nombre, descripción, especialidad o clasificación de relación con salud sexual, VIH/ITS, PrEP/PEP, sexualidad, LGBT/LGBTI, sustancias, adicciones, Chemsex, SLAM, reducción de riesgos/daños o apoyo comunitario relacionado.

## Exclusiones
Farmacias, odontología, veterinaria, podología, maternidad, ortopedia, optometría, oftalmología, fisioterapia y otros servicios no relacionados se excluyen.

## Cobertura y límites
La búsqueda admite ciudad, región, país o lugar y es independiente del país. OSM/Overpass no permite afirmar que se hayan encontrado literalmente todos los recursos existentes; Will no inventará resultados ni presentará una ausencia de datos como inexistencia.
