# Ronda 1 — Pruebas de usuarios reales

## Alcance

La Ronda 1 comprende diez pruebas reales, distribuidas en dos tandas de cinco.

### R1A — Tanda 1

TEST-001 a TEST-005

Compuesta por:
- 2 perfiles sanitarios.
- 2 perfiles comunitarios/asociativos.
- 1 usuario con experiencia Chemsex.

### R1B — Tanda 2

TEST-006 a TEST-010

Compuesta por:
- 2 perfiles de mujer.
- 3 perfiles de hombre.
- Perspectivas de sexualidad, ausencia de consumo, experiencia Slam y experiencia sexual sin Slam ni Chemsex.

## Secuencia

1. Ejecutar R1A.
2. Registrar cada prueba individual.
3. Identificar incidencias, observaciones y patrones.
4. Analizar los hallazgos antes de ejecutar R1B.
5. Ejecutar R1B.
6. Consolidar los resultados de toda la Ronda 1.

## No condicionamiento

Las personas participantes deben poder utilizar Will de forma espontánea. La orientación previa debe limitarse a explicar cómo acceder a la aplicación y, cuando proceda, cómo aportar feedback.

No se deben prescribir preguntas concretas como recorrido obligatorio.

## Dimensiones prioritarias

- técnico;
- voz y micrófono;
- interacción;
- experiencia de usuario;
- calidad conversacional;
- contenido y contextualización;
- recursos;
- accesibilidad;
- cobertura de necesidades.
